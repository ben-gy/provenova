How often do quantum operations fail?

A quantum computer works by entangling qubits, two at a time, and every one of those operations can go wrong. Each dot is a published record for one kind of hardware; the line follows the best result so far. Lower is better. Below the dashed line (roughly 1 failure in 100), error correction can start to win: extra qubits fix more errors than they add.

Is error correction working yet?

Useful quantum computers will spread each reliable "logical" qubit across many physical ones, so that errors can be caught and fixed. The code distance measures how many errors a code can catch: distance 7 can correct any 3. Bigger is better, but only once the hardware is below the threshold. Stars mark experiments reported as below threshold.

{% call chart_card('chart-qec', 'Published experiments') %} Largest code distance in each published error-correction experiment. Repetition codes only guard against one kind of error, so their large distances are easier to reach than surface or colour codes. {% endcall %}

How big are the machines getting?

Qubit counts are the number everyone quotes, but on their own they say little: a thousand noisy qubits can do less than a hundred good ones. Read this chart together with the error charts. The biggest neutral-atom figures are atoms trapped in one array, not all yet usable in a single computation.

How to read the labels

Not all numbers deserve the same trust. Every figure on Provenova carries one of these.

{{ evidence('Published experiments') }}
A result reported in a paper (peer-reviewed or a preprint), usually a record on a few qubits in a lab.
{{ evidence('Device calibration') }}
The machine's own measurement of every qubit and gate on a given day, published by the vendor.
{{ evidence('Independent benchmark') }}
The same open test run on many vendors' machines by a third party (Metriq).
{{ evidence('Vendor claim') }}
A number from a company's own announcement or spec sheet, not independently checked here.
{{ evidence('Resource estimate') }}
A paper's calculation of what a future task would need. It depends on its stated assumptions.
{{ evidence('Programme announcement') }}
A decision announced by a funder or government programme, reported with its source.
